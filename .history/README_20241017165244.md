# Atte
企業の勤怠管理システムです。勤務開始、勤務終了、休憩開始、休憩終了が打刻できます。  
また、休憩時間と勤務時間が自動で計算され、日付別やユーザー別で勤怠一覧を確認できます。  

![](Atte.html-1.png)

## 作成した目的
社員の人事評価のため作成しました。

## アプリケーションURL
* 開発環境 : http://localhost/  
上記のトップページにアクセスするためには会員登録が必須となっています。  
会員登録にはメール認証が必要であり、メール認証はMailHogを利用しています。  
会員登録後、MailHogにアクセスし認証メールが届いていれば認証ボタンを押してください。トップページに移動します。  
もし認証メールが届いていなければ再送ボタンを押してください。  
会員登録画面 : http://localhost/register  
MailHog : http://localhost:8025
* phpmyadmin : http://localhost:8080

## 機能一覧
* 会員登録・ログイン・ログアウト機能
* 勤務開始・勤務終了機能  
日を跨いだ時点で翌日の出勤操作に切り替えとなります。  
* 休憩開始・休憩終了機能  
1日に何度でも休憩が可能です。
* 日付別勤怠情報取得  
日付一覧ページで日付毎に勤怠情報（名前、勤務開始時刻、勤務終了時刻、休憩時間、勤務時間）が5件ずつ表示されます。
* ユーザー別勤怠情報取得  
ユーザー一覧ページで登録ユーザーが一覧で表示され、ユーザー毎の勤怠情報が確認できます。

## 環境構築
**Dockerビルド**
1. `git clone git@github.com:Haruka-Wada/Atte.git`
2. DockerDesktopアプリを立ち上げる
3. `docker-compose up -d --build`

**Laravel環境構築**
1. `docker-compose exec bash`
2. `composer install`
3. 「.env.example」ファイルを「の環境変数を変更  
.env  
DB_CONNECTION=mysql  
DB_HOST=mysql  
DB_PORT=3306  
DB_DATABASE=laravel_db  
DB_USERNAME=laravel_user  
DB_PASSWORD=laravel_pass  
MAIL_MAILER=smtp  
MAIL_HOST=mailhog  
MAIL_PORT=1025  
MAIL_USERNAME=null  
MAIL_PASSWORD=null  
MAIL_ENCRYPTION=null  
MAIL_FROM_ADDRESS="hello@example.com"  
MAIL_FROM_NAME="${APP_NAME}"  
4. php artisan key:generate  
5. php artisan migrate

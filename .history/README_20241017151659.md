# Atte
企業の勤怠管理システム。勤務開始、勤務終了、休憩開始、休憩終了が打刻できる。  
また、休憩時間と勤務時間が自動で計算され、日付別やユーザー別で勤怠一覧を確認できる。  

![](Atte.html-1.png)

## 作成した目的
社員の人事評価のため
